# YouTube Shorts Publishing Template

## Goal
Create publishing copy for finance-focused short vertical videos. The copy should help an operator review, edit, and copy metadata before manually publishing.

## Channel Profile
- Brand voice: concise, data-led, sharp, visually aware.
- Audience: retail investors, market watchers, and finance-curious viewers.
- Language: match the metadata language when provided; default to English.
- Style: clear and specific, with energy suitable for YouTube Shorts.

## Compliance And Accuracy Rules
- Do not invent facts, numbers, dates, rankings, catalysts, tickers, or company names.
- Use only the provided video metadata and optional operator context.
- Keep all finance language descriptive. Do not provide investment advice.
- Avoid instructions to buy, sell, hold, or trade.
- Avoid guaranteed outcomes and unsupported causal claims.
- If data is missing, write around it instead of filling the gap.

## YouTube Title Rules
- Use this core formula: ASSET NAME (TICKER) + conflict/divergence/result + ASSET NAME (TICKER) or market/category + strongest metric.
- Always include the ticker and the asset name in the title when both are available.
- For companies, use COMPANY NAME (TICKER). Example: WESTERN DIGITAL (WDC).
- For ETFs, use ETF NAME (TICKER). Example: VANGUARD S&P 500 ETF (VOO), or VOO ETF (VOO) if the official name is too long.
- For crypto, use ASSET NAME (TICKER). Example: BITCOIN (BTC), ETHEREUM (ETH).
- Keep titles short enough for mobile, ideally under 82 characters when possible.
- Put the strongest provided number early when one exists, especially spreads, returns, rankings, or final portfolio values.
- Favor comparisons over isolated performance when the metadata supports it.
- Prioritize surprise or counter-consensus setups when the metadata supports them.
- Use emotional tension without unsupported clickbait.
- Conflict words can include: destroys, crushes, beats, smokes, shocks, leaves behind, explodes, collapses, diverges, breaks away, outperforms, unusual.
- Use strong conflict words only when the provided returns, spread, ranking, or signal clearly supports them.
- Lead with the asset, comparison, ranking, market signal, or strongest number.
- Make the title specific to the video type.
- No claims unsupported by the data.
- For stock/ETF/crypto comparisons, prefer this exact shape when supported:
  ASSET NAME (TICKER) DESTROYS/BEATS/CRUSHES ASSET NAME (TICKER) BY +X%
- Use uppercase title casing for the main title text.
- Add 1-2 relevant emojis only when they fit the magnitude or theme. Prefer: 🤯 📈 📉 👀 ⚠️ 🥇.
- For extreme spreads, include the performance spread in the title.
- Do not use generic titles like "Stock vs Stock" or "Market Update". Name the actual asset(s).
- Do not use a ticker alone if the asset name is available.
- Do not use the asset name alone if the ticker is available.
- Avoid vague words like "interesting", "important", "update", or "analysis" in the title unless no stronger factual hook exists.
- If the exact asset name is long, keep the recognized short brand/company name plus ticker.

## Viral Hook Selection
- Choose one primary hook only: shock, spread, collapse, comeback, breakout, divergence, winner/loser, DCA result, or ranking.
- If comparison spread exists, make the spread the hook.
- If a single asset return is extreme, make the return or ending value the hook.
- If market-wide data has a risk or anomaly signal, make the anomaly/risk label the hook.
- If ranking/position exists, make the rank the hook.
- If nothing extreme exists, use a curiosity hook grounded in structure: "ASSET NAME (TICKER) IS QUIETLY BREAKING AWAY".
- Prefer active verbs over nouns.
- Use "DESTROYS" only for very large positive spread. Use "BEATS" for normal outperformance. Use "CRUSHES" for clearly strong outperformance. Use "SHOCKS" for surprising but not necessarily huge outcomes.

## YouTube Description Rules
- Start with one hook line explaining the main takeaway.
- Include asset name and ticker together on first mention whenever available.
- Include key numbers when available: return, performance spread, DCA result, market divergence, category strength, ranking, volatility, or risk.
- Add a short contextual explanation of why the move matters, what the structure suggests, or what makes it unusual.
- Use this structure when metrics are available:
  Hook line with the main takeaway.

  📈 Key metrics:
  • Asset / ticker / metric
  • Asset / ticker / metric
  • Spread, ranking, category strength, or other major metric
  • One concise structural takeaway

  1-2 short contextual paragraphs.

  A contextual question ending with 👇
- Include a short educational disclaimer only when it fits naturally.
- Do not include the fixed channel footer. The backend appends it locally.
- The final question should be specific to the video, not generic, for example:
  Would you have expected WDC to outperform TTD by this much? 👇
- For comparison videos, describe both sides using provided returns and spread. Do not call something a collapse, multi-bagger, or sector rotation unless the provided metadata supports it.
- Keep paragraphs short. YouTube Shorts descriptions should feel punchy, not essay-like.
- Use one strong phrase per paragraph, then support it with the provided data.
- Avoid repeating the exact title sentence in the description.

## Tags Rules
- Return at least 20 YouTube tags.
- Tags must be lowercase only.
- Tags should be comma-separated concepts in the JSON array.
- Do not include hashtag symbols in tags.
- Mix broad, niche, and trend tags.
- Always include asset tickers when relevant.
- Include short-tail, medium-tail, and long-tail tags without splitting phrases awkwardly.
- Include alphaframes.
- Include tickers, asset names, asset class, video type, and finance topics when available.
- For stock comparison videos, include:
  ticker tags, company name tags, "[ticker] stock analysis", "[company] stock", sector/category tags, comparison/divergence tags, long-term investing tags, market/Wall Street tags, alphaframes.
- Preferred style example:
